# Amigo Secreto

Aplicación web interactiva para realizar un sorteo de amigo secreto de forma sencilla y divertida.

---

### Funcionalidades

- Agregar nombres de amigos.
- Validación de nombre vacío y nombres duplicados.
- Lista visible de participantes.
- Sorteo aleatorio del amigo secreto.
- Modal de advertencias elegante.
- Botón para limpiar y reiniciar la lista.
- Diseño responsive y visualmente atractivo.
---

### Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

---

### Cómo usar

1. Clona o descarga este repositorio desde GitHub.
2. Abre el archivo `index.html` en tu navegador.
3. ¡Comienza a agregar nombres y sortear!
